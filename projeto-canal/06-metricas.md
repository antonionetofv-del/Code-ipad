# 06 — Métricas

## A única métrica que importa nos primeiros 90 dias

**Retenção.** Não é seguidor, não é view, não é curtida.

O algoritmo do TikTok e do YouTube decide entregar o seu vídeo para mais gente
com base em quanto tempo as pessoas ficam. Seguidor é consequência. Perseguir
seguidor te faz fazer vídeo de dancinha e destruir o nicho.

## Metas de retenção

| Formato | Ruim | Aceitável | Bom | Excelente |
|---|---|---|---|---|
| Curto (61–90s) | < 30% | 30–40% | 40–55% | > 55% |
| Longo (8–12 min) | < 25% | 25–35% | 35–45% | > 45% |

Além disso, no curto olhe a **retenção aos 3 segundos**. Se menos de 70% das
pessoas passam dos 3 segundos, o problema é o gancho — e só o gancho. Não
adianta melhorar o resto do vídeo.

## Planilha de acompanhamento

Crie uma planilha no Google com estas colunas, uma linha por vídeo:

| Coluna | O que anotar |
|---|---|
| Data | Data da publicação |
| Plataforma | TikTok / Shorts / YouTube longo |
| Série | Qual das 5 séries |
| Gancho | O tipo de gancho usado (dor, número, erro...) |
| Título | Título completo |
| Views 48h | Views nas primeiras 48 horas |
| Views 7d | Views em 7 dias |
| Retenção % | Percentual médio assistido |
| Ret. 3s % | Só para curtos |
| Comentários | Quantidade |
| Seguidores ganhos | Quantos vieram desse vídeo |
| Cliques no link | Se houver afiliado |
| Nota | O que você faria diferente |

Preencha **na terça de cada semana**, com os dados dos vídeos de 48h atrás.
Leva 10 minutos e é o que separa quem melhora de quem só publica.

## Como ler os dados

| Sintoma | Diagnóstico | O que fazer |
|---|---|---|
| Retenção 3s baixa | Gancho fraco | Reescreva só os 2 primeiros segundos e republique |
| Retenção 3s boa, retenção final baixa | Prometeu e não entregou | Entregue o valor mais cedo, corte enrolação |
| Views boas, zero comentário | Não deu motivo para responder | Termine sempre com pergunta específica |
| Views boas, zero seguidor | Vídeo bom, canal indefinido | O público não entendeu o que você faz sempre |
| Views baixas em tudo | Tema não tem demanda | Vá para pauta com dor mais óbvia |
| Um vídeo estourou, os outros não | Achou a veia | **Refaça esse vídeo de 5 jeitos diferentes** |

Essa última linha é a mais valiosa da tabela. Quando um vídeo performa muito
acima da média, a reação certa não é comemorar e seguir em frente — é fazer
mais cinco variações do mesmo tema imediatamente.

## Frequência de análise

| Quando | O que olhar |
|---|---|
| Diário | Só os comentários. Responder, nada mais. |
| Semanal | Retenção dos 7 vídeos, qual gancho ganhou |
| Mensal | Crescimento de seguidor, receita, os 3 melhores e os 3 piores |
| A cada 90 dias | O nicho continua de pé? A escada de receita subiu um degrau? |

**Não abra o painel de métricas todo dia.** Vídeo leva de 3 a 30 dias para
maturar. Olhar de hora em hora só gera ansiedade e decisão errada.

## Sinais de que está funcionando (mesmo com número pequeno)

Antes do dinheiro aparecer, esses sinais aparecem. Se você tem esses três,
continue mesmo com 400 seguidores:

1. Alguém comentou "eu fiz isso e funcionou"
2. Alguém mandou mensagem no direct fazendo pergunta sobre o assunto
3. Um vídeo antigo voltou a ganhar views sozinho

## Sinais de que precisa mudar

- 60 dias publicando todo dia e nenhum vídeo passou de 3 mil views
- Retenção 3s abaixo de 50% em quase tudo, mesmo trocando o gancho
- Você não consegue mais pensar em pauta — sinal de nicho estreito demais
- Você não assistiria ao próprio vídeo até o fim

Nos três primeiros casos, ajuste o formato. No quarto, o problema é o conteúdo.
