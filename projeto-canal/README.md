# Projeto Canal — negócio novo, do zero

Pasta autossuficiente. Nada aqui depende de design gráfico, de cliente antigo
ou de qualquer trabalho anterior. É um projeto novo, começando do zero.

## Parâmetros definidos

| Item | Definição |
|---|---|
| Formato | Faceless — sem rosto, sem voz própria obrigatória |
| Tempo/dia | 2 a 3 horas |
| Orçamento | R$ 0 em ferramentas novas (Claude Pro já disponível + gratuitas) |
| Plataformas | YouTube (longo + Shorts) e TikTok |
| Idioma | Português do Brasil |

## Regra número um

Publicar todo dia por 90 dias sem mudar de nicho. O algoritmo leva de 60 a 90
dias para entender do que é o canal. Quem troca de assunto no dia 30 reinicia
o contador e nunca sai do lugar.

Só 3% dos canais faceless chegam à monetização. Os outros 97% param antes do
dia 60. A diferença é constância, não talento.
